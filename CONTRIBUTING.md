# Contributing to Awesome Social Security Claiming Strategies

Thank you for your interest in contributing! This list aims to be the most accurate, formula-rich, and practically useful GitHub resource on Social Security claiming optimization.

## Standards

**We prioritize:**
- Accuracy over volume — every resource must be verifiable against SSA.gov or peer-reviewed research
- Code that runs — all Python/JS examples must be tested and produce correct output
- Dated content — always note when rules/figures were last verified (SS rules change annually with COLA adjustments)

**We do not accept:**
- Affiliate links or commercial products without clear disclosure
- Resources behind hard paywalls with no free preview
- Opinion pieces without data backing
- Content that could be construed as specific financial advice

## How to Contribute

1. Fork this repository
2. Add your resource to the appropriate section in `README.md`
3. Format: `- [Title](URL) — one-line description of what makes this resource valuable`
4. If adding code: include a brief comment explaining what it calculates and expected output
5. Open a Pull Request with a clear description of what you added and why

## Accuracy Requirements

All numerical claims (benefit reduction percentages, COLA rates, earnings thresholds) must:
- Reference the source (SSA.gov publication, NBER paper, etc.)
- Include the year the data applies to
- Be updated when SSA announces COLA adjustments each October

## Reporting Outdated Information

Social Security rules change every year. If you find outdated figures:
- Open an Issue with the title format: `[OUTDATED] Section name — what's wrong`
- Include the correct current value and its source

## Code of Conduct

Be constructive. This is a technical resource list — focus on accuracy and utility, not debate about SS policy.
